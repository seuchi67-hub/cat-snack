# 小猫接零食

原生 HTML、CSS、JavaScript 和 Canvas 的纯 H5 小游戏，无构建步骤、无第三方依赖、无网络资源请求。

## 运行

直接双击 `index.html`，用现代浏览器打开即可。三个游戏文件必须放在同一文件夹内。

手机测试时，可将这些文件放到静态网站服务器，再用手机浏览器访问该地址。若电脑安装了 Python，可在本文件夹运行 `python -m http.server 8000`，电脑打开 `http://localhost:8000`；手机与电脑连接同一 Wi-Fi 后，访问 `http://电脑的局域网IP:8000`，需要电脑防火墙允许访问。此服务器仅供本地预览，游戏本身不需要后端。

## 操作与规则

- 点击“开始接零食”；手机在游戏区左右拖动，电脑使用左右方向键，也可用鼠标拖动。
- 接住饼干加 10 分，碰到灰色毛球扣 15 分，最低 0 分。漏接不扣分。
- 一局为 60 秒有效游戏时间，结算后可以重新开始或返回开始页。
- 右上角可暂停；切换窗口、切到后台时自动暂停，返回后点击“继续游戏”。
- 最高分保存在当前浏览器的 localStorage 中；隐私设置或存储异常时仍可游戏，当前页面内会保留最高分。
- 不同浏览器、不同网址、直接打开文件和通过 HTTP 打开之间，最高分可能不共享。清除浏览器数据会清除纪录。

## 文件

- `index.html`：开始页、游戏页、结算页和暂停界面。
- `style.css`：竖屏适配、按钮、面板样式。
- `game.js`：Canvas 绘图、触摸/键盘控制、碰撞计分、计时和存储。
- `tests/smoke.cjs`：可选的本地逻辑验证，安装 Node.js 后运行 `node tests/smoke.cjs`，无需安装依赖。

## 后续发布

当前是纯静态 H5 项目，保留相对资源路径。后续可将 `index.html`、`style.css`、`game.js` 一同交给静态托管或按目标平台届时的纯 H5 接入要求打包。此版本未接入平台 SDK，未执行平台审核验证，也未发布；不包含 APK 或 Tap 小游戏工程。

发布前请在实际手机上检查触摸、横竖屏切换、浏览器工具栏变化、后台恢复和完整 60 秒流程。
